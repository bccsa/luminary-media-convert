# API endpoints and environment (detail)

## API Endpoints

Auth column: **instance** = the instance `X-API-Key` token; **session** = `Bearer sess_*`; **read** = `?token=read_*`; **origin** = browser Origin allowlist; **query token** = `?token=` carrying the session token.

### Encoding sessions (`/api/sessions`)

| Method | Path                                                  | Auth                              | Description                                                                                                                                                                                                                                                           |
| ------ | ----------------------------------------------------- | --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| POST   | `/api/sessions`                                       | token                             | Create a session (S3 + encryption + segment/byte-range/thumbnail options). Returns `{ sessionId, sessionToken }`                                                                                                                                                      |
| GET    | `/api/sessions`                                       | token                             | List every session on this instance, newest first, including session tokens (the UI is the only holder of the instance token)                                                                                                                                         |
| POST   | `/api/sessions/:id/local-file`                        | token, session                    | Attach an absolute path to a file already on this machine. Returns once probed                                                                                                                                                                                        |
| POST   | `/api/sessions/:id/encode`                            | token, session                    | Submit the encode config and enqueue. `202`                                                                                                                                                                                                                           |
| POST   | `/api/sessions/:id/continue`                          | token, session                    | Run a failed encode again with the settings it was started with, continuing from what already reached storage when it can (`canResume`). `202`; `400` unless the session failed with its source and settings still here                                               |
| POST   | `/api/sessions/:id/stop`                              | token, session                    | End a running encode and keep what it made: the session becomes `failed` with `stopped: true`, to be continued with `/continue`. `202`; `400` when it is not encoding                                                                                                 |
| GET    | `/api/sessions/:id`                                   | token, session, read              | Poll status: probe results, progress, `hlsUrl`, `cmsPending`, `canRetry`, `queuePosition`, trim segments, files on completion (no key — see `/key`)                                                                                                                   |
| GET    | `/api/sessions/:id/events`                            | query token (session **or** read) | SSE event stream. The first event on every connection is a snapshot of the session's current state (`hlsUrl`, `masterPlaylist`, `cmsPending`, …)                                                                                                                      |
| POST   | `/api/sessions/:id/ack?token=read_…`                  | read (only)                       | The CMS confirms its document has stored `{ hlsUrl }`. `204`; counts only when it equals the session's current `hlsUrl`, ignored otherwise. `401` for any other token or a session no longer held; `404` from encoders older than the route, which a CMS ignores      |
| GET    | `/api/sessions/:id/key`                               | token, session, read              | Masked AES-128 session key `{ maskedKeyHex }` (XOR `SHA-256(sessionId)[0..16]`, self-inverse). 404 when the session has no encryption                                                                                                                                 |
| DELETE | `/api/sessions/:id`                                   | token, session                    | Cancel and delete. Allowed from `created`, `uploading`, `uploaded`, `queued`, `encoding`, `failed`, `completed` — the terminal two included, which is the only way their disk is reclaimed. `encrypting` and `uploading_to_s3` are refused: the pipeline is mid-write |
| GET    | `/api/sessions/:id/chapters?lang=en`                  | token, session                    | Read the language's chapters: the master's index line, else the file recorded during the encode, else `chapters/<lang>.vtt`. Empty `{ vtt: '' }` when there are none                                                                                                  |
| PUT    | `/api/sessions/:id/chapters?lang=en`                  | token, session                    | Write `chapters/<lang>_<8hex>.vtt` (≤ 1 MiB, `text/vtt`) plus the legacy `chapters/<lang>.vtt`. `200` JSON (was `204`): once the master is published, a new revision and `{ hlsUrl, masterPlaylist, etag, published }` (gated, see below); during the encode `{}`     |
| GET    | `/api/sessions/:id/waveform`                          | query token                       | Waveform peaks for the source (`{ peaks, numPeaks }`)                                                                                                                                                                                                                 |
| GET    | `/api/sessions/:id/source`                            | query token                       | The source file as it is on disk, with byte ranges (206/416, `HEAD`): the preview of a source the browser plays directly. 404 before a file is attached or once it is gone from disk                                                                                                              |
| GET    | `/api/sessions/:id/preview/playlist.m3u8`             | query token                       | Preview master playlist (`?audio=<index>`)                                                                                                                                                                                                                            |
| GET    | `/api/sessions/:id/preview/r:rendition/playlist.m3u8` | query token                       | Preview rendition playlist                                                                                                                                                                                                                                            |
| GET    | `/api/sessions/:id/preview/r:rendition/:filename`     | query token                       | Preview MPEG-TS segment                                                                                                                                                                                                                                               |
| GET    | `/api/sessions/:id/thumbnails/thumbnails.vtt`         | query token                       | Source storyboard WebVTT (cues rewritten to absolute, token-carrying sprite URLs; `X-Storyboard-Complete`)                                                                                                                                                            |
| GET    | `/api/sessions/:id/thumbnails/:filename`              | query token                       | Source storyboard sprite sheet                                                                                                                                                                                                                                        |
| POST   | `/api/sessions/:id/thumbnails/regenerate`             | token, session                    | Before an encode or after a failed one: sample the source storyboard again. In an edit session: rebuild the video's storyboard from the video as `thumbnails/thumbnails_<8hex>.vtt` + new sprites, published as a new revision when done. `202`                       |
| GET    | `/api/sessions/:id/thumbnails/regenerate`             | token, session                    | Progress of an edit session's storyboard rebuild; `404` until one is started                                                                                                                                                                                          |

### Edit session: the post's existing video (`mode: 'edit'`)

Only for an edit session (`409` otherwise). Every change writes a new master revision (`master_rN.m3u8`) and announces its `hlsUrl`; nothing is overwritten or deleted. Save responses are `EncodedMedia` with `hlsUrl`, `masterPlaylist` and `published` (`true` when the CMS stored the revision within ~10 s, `false` when it has not yet; absent without a CMS).

| Method | Path                                                   | Auth           | Description                                                                                                                                                                  |
| ------ | ------------------------------------------------------ | -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GET    | `/api/sessions/:id/media`                              | token, session | The current revision: audio tracks, angles, subtitles, chapter languages, `encrypted`, its `etag`, `hlsUrl` and `masterPlaylist`, and a running `adding` / `addingAngle` job |
| PUT    | `/api/sessions/:id/media/audio-tracks`                 | token, session | Change audio tracks' `LANGUAGE` / `NAME`, or remove some, over `ifMatch`                                                                                                     |
| POST   | `/api/sessions/:id/media/audio-sources`                | token, session | List a local file's audio tracks, to add one from                                                                                                                            |
| POST   | `/api/sessions/:id/media/audio-tracks`                 | token, session | Add an audio track from a local file: encoded to every audio group, uploaded to folders of its own, then a new revision. Background job, `202`                               |
| GET    | `/api/sessions/:id/media/subtitles/:language`          | token, session | One language's subtitles as WebVTT (decrypted when the video is encrypted)                                                                                                   |
| PUT    | `/api/sessions/:id/media/subtitles/:language`          | token, session | Write one language's subtitles under new file names, adding the language when new, over `ifMatch`                                                                            |
| DELETE | `/api/sessions/:id/media/subtitles/:language?ifMatch=` | token, session | Take one language out of the master; its files stay                                                                                                                          |
| PUT    | `/api/sessions/:id/media/video-angles`                 | token, session | Rename angles, or remove some (their files stay), over `ifMatch`                                                                                                             |
| POST   | `/api/sessions/:id/media/video-sources`                | token, session | List a local file's video streams, to add an angle from                                                                                                                      |
| POST   | `/api/sessions/:id/media/video-angles`                 | token, session | Add a camera angle from a local file, matched to the main angle's ladder, then a new revision. Background job, `202`                                                         |

**`409` codes** on every write that creates a revision (these saves, `PUT /chapters` once published) and on the job starts (`POST /media/audio-tracks`, `POST /media/video-angles`, `POST /thumbnails/regenerate` in an edit session), as `{ statusCode: 409, message, code }`:

- `CMS_NOT_ACKNOWLEDGED` — the CMS page for the post is not following the session (refused at once), or is following it but has not stored the current version (refused after a ~10 s wait for the ack). Nothing was written.
- `CHANGED_ELSEWHERE` — another machine already wrote the next revision. The session has moved to the newest one (the body carries its `hlsUrl`); reload and save again.
- `ETAG_MISMATCH` — `ifMatch` names an older revision than the current one.

### CMS handshake (`/api/cms`)

| Method | Path                | Auth   | Description                                                                                                                                                                                                                                                                |
| ------ | ------------------- | ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GET    | `/api/cms/health`   | none   | `{ status: 'ok', apiVersion }` — is the local encoder installed and running                                                                                                                                                                                                |
| POST   | `/api/cms/sessions` | origin | Open (or reuse) a session for a CMS document; returns `readToken` + `eventsUrl`. With `mode: 'edit'` + `existingMedia` it opens the existing video, and the response's `hlsUrl` names the revision opened — the newest in the folder, which may be newer than the one sent |

### HLS edit (`/api/hls`, stateless, inline S3 credentials, read-only)

`POST /api/hls/mutate` and `POST /api/hls/chapters/write` are gone: nothing called them, and they wrote in place. Every write now goes through a session.

| Method | Path                     | Auth  | Description                                                                                                                                                                                                    |
| ------ | ------------------------ | ----- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| POST   | `/api/hls/read`          | token | Fetch and parse a master playlist; returns the parsed master + current ETag                                                                                                                                    |
| POST   | `/api/hls/discover`      | token | Scan a folder prefix for HLS masters / angles                                                                                                                                                                  |
| POST   | `/api/hls/chapters/read` | token | Read a language's chapters under a folder prefix, resolved through the newest master revision there (highest `*_r<N>.m3u8`, else `master.m3u8`): its index line, else `chapters/<lang>.vtt`; `404` when absent |
| POST   | `/api/hls/waveform/read` | token | Read `waveform.json` under a prefix; `404` when absent                                                                                                                                                         |

## Environment Variables

### API (`api/.env`, standalone only — the Electron host passes these in code)

| Variable                          | Default                       | Description                                                                                                                                  |
| --------------------------------- | ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `LOCAL_API_TOKEN`                 | —                             | The instance API token accepted on `X-API-Key`. Unset disables key auth entirely. `MASTER_API_KEY` is still read, with a deprecation warning |
| `PORT`                            | `3000` (standalone `main.ts`) | HTTP port. The embedded default is `31711` (`DEFAULT_PORT`)                                                                                  |
| `HOST`                            | `127.0.0.1`                   | Bind address                                                                                                                                 |
| `WORK_DIR`                        | `./work`                      | Scratch directory for sessions, previews, sidecars                                                                                           |
| `CMS_ALLOWED_ORIGINS`             | —                             | Comma-separated origins trusted without asking (there is no approver standalone)                                                             |
| `FFMPEG_PATH` / `FFPROBE_PATH`    | PATH lookup                   | Absolute paths to the binaries                                                                                                               |
| `FFMPEG_TIMEOUT_MS`               | none                          | Max FFmpeg runtime before a forced kill                                                                                                      |
| `FFMPEG_THREADS`                  | —                             | Thread count passed to FFmpeg                                                                                                                |
| `DISK_RESERVE_BYTES`              | `2147483648`                  | Free space to keep in hand on the work volume                                                                                                |
| `SESSION_ABANDONED_MAX_AGE_HOURS` | `6`                           | How long an idle session may sit before it is swept                                                                                          |
| `SESSION_CLEANUP_CRON`            | `0 * * * *`                   | Sweep schedule                                                                                                                               |
| `S3_UPLOAD_STALL_TIMEOUT_MS`      | `300000`                      | Stall detector for S3 uploads (measured in bytes sent, not files completed)                                                                  |
