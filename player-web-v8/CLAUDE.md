# player-web-v8/ — retired, frozen

## Overview

- **`player-web-v8/`** — **Retired and frozen**: the Video.js 8 / VHS player `player-web` replaced (`VideoJsAdapter`, vhs xhr seam, `videojs-mobile-ui`). Kept because it is the only web player with a YouTube mode (`videojs-youtube`, plus the Capacitor frame protocol). Outside `build:libs`, `ci:libs` and CI; its demo runs on port 5183. Package name `@luminary-media-converter/player-web-v8`.
